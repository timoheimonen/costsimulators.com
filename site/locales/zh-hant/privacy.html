簡要說明

  • 所有計算都在你的瀏覽器中於本機執行。這些工具絕不會把你輸入的數字傳送到伺服器。

  • 本網站架設於 Cloudflare，Cloudflare 會處理基本的技術性請求資料，以提供並保護網站。

2. 留在你裝置上的資料

網站上的每個計算機都使用 JavaScript 完全在你的瀏覽器中執行。你輸入的數值，例如時薪、與會人數、價格或數量，只會在你的裝置上處理，不會傳送到、儲存在或記錄於任何為本網站運作的伺服器。

為了記住你偏好淺色或深色主題，網站會在瀏覽器的本機儲存空間（local storage）中儲存一個值（costsimulators-theme），內容只有 light 或 dark 一個字。如果你從語言選單中選擇語言，網站也會儲存這個選擇（costsimulators-lang，例如 zh-Hant），以便下次用你選擇的語言開啟網站。這些值絕不會傳送到任何地方，你也可以隨時清除瀏覽器的網站資料來刪除它們。

部分功能會使用瀏覽器內建的能力：把連結複製到剪貼簿、開啟裝置的分享選單，以及在會議計時器運作時讓螢幕保持開啟。這些都在本機進行，而且只在你使用時才會發生。

3. 可分享的連結

工具的設定會保存在網址中，方便你把計算結果加入書籤或分享出去。當你開啟這類連結時，其中的數值是瀏覽器所請求網址的一部分，因此可能出現在下文所述的技術性請求資料中。如果你分享連結，收到連結的人都能看到這些數值。請避免在分享的連結中放入你認為機密的內容。

4. 網站代管與技術資料（Cloudflare）

本網站由 Cloudflare, Inc. 代管與傳送（Cloudflare Workers 及其內容傳遞網路）。每當你的瀏覽器載入網頁時，Cloudflare 必然會收到該請求的標準技術資訊，可能包括：

  • 你的 IP 位址，以及據此推估的大略位置；
  • 所請求的網址、日期和時間；
  • 瀏覽器和作業系統資訊（user agent）、來源網頁及類似的請求標頭。

這些資料只用於提供網站、維持網站的安全與穩定、防範濫用與攻擊，以及診斷技術錯誤。請求紀錄只會保存很短的時間，通常只有幾天，不會用來建立訪客的個人檔案、與其他資料結合，也不會用於行銷。

為了保護網站，Cloudflare 在某些情況下可能會設定絕對必要的安全性 Cookie，例如需要區分真人與自動化流量時。本網站本身不設定任何 Cookie。

Cloudflare 代表本網站擔任資料處理者。詳情請參閱 Cloudflare 隱私權政策。
