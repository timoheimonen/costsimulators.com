Πολιτική απορρήτου

Το costsimulators.com έχει φτιαχτεί ώστε να λειτουργεί χωρίς να συλλέγει τίποτα για εσάς. Αυτή η σελίδα εξηγεί ποια ελάχιστα δεδομένα εμπλέκονται στην παροχή του ιστότοπου και ποιος τα επεξεργάζεται.

Τελευταία ενημέρωση 28 Σεπτεμβρίου 2026

Η σελίδα αυτή είναι μετάφραση. Σε περίπτωση απόκλισης από την αγγλική έκδοση, υπερισχύει η αγγλική έκδοση.

Με λίγα λόγια

  • Όλοι οι υπολογισμοί γίνονται τοπικά στον browser σας. Τα εργαλεία δεν στέλνουν ποτέ σε διακομιστή τους αριθμούς που συμπληρώνετε.
  • Χωρίς λογαριασμούς, εργαλεία ανάλυσης (analytics), διαφημίσεις, pixel παρακολούθησης και scripts τρίτων.
  • Ο ιστότοπος δεν ορίζει cookies. Τα μόνα που αποθηκεύονται στη συσκευή σας είναι οι επιλογές θέματος και γλώσσας.
  • Ο ιστότοπος φιλοξενείται στην Cloudflare, η οποία επεξεργάζεται βασικά τεχνικά δεδομένα των αιτημάτων για να τον παρέχει και να τον προστατεύει.

2. Τι μένει στη συσκευή σας

Κάθε εργαλείο του ιστότοπου λειτουργεί εξ ολοκλήρου στο πρόγραμμα περιήγησής σας (browser) με JavaScript. Οι τιμές που συμπληρώνετε, όπως ωριαίες αμοιβές, αριθμός συμμετεχόντων, τιμές ή ποσότητες, υποβάλλονται σε επεξεργασία μόνο στη συσκευή σας και δεν διαβιβάζονται, δεν αποθηκεύονται ούτε καταγράφονται σε κανέναν διακομιστή που λειτουργεί για αυτόν τον ιστότοπο.

Για να θυμάται αν προτιμάτε το ανοιχτό ή το σκούρο θέμα, ο ιστότοπος αποθηκεύει μία μόνο τιμή (costsimulators-theme) στον τοπικό χώρο αποθήκευσης (local storage) του browser σας. Περιέχει μόνο τη λέξη light ή dark. Αν διαλέξετε γλώσσα από το μενού γλωσσών, ο ιστότοπος αποθηκεύει και αυτή την επιλογή (costsimulators-lang, για παράδειγμα el), ώστε την επόμενη φορά να ανοίξει στη γλώσσα σας. Αυτές οι τιμές δεν αποστέλλονται ποτέ πουθενά, και μπορείτε να τις διαγράψετε οποιαδήποτε στιγμή, καθαρίζοντας τα δεδομένα ιστοτόπων στον browser σας.

Ορισμένες λειτουργίες χρησιμοποιούν δυνατότητες ενσωματωμένες στον browser σας: την αντιγραφή ενός συνδέσμου στο πρόχειρο, το άνοιγμα του μενού κοινοποίησης της συσκευής σας και τη διατήρηση της οθόνης αναμμένης όσο τρέχει το χρονόμετρο σύσκεψης. Όλα αυτά γίνονται τοπικά και μόνο όταν τα χρησιμοποιείτε.

3. Σύνδεσμοι κοινοποίησης

Οι ρυθμίσεις των εργαλείων κρατιούνται στη διεύθυνση της σελίδας, ώστε να μπορείτε να αποθηκεύσετε έναν υπολογισμό στους σελιδοδείκτες ή να τον μοιραστείτε. Όταν ανοίγετε έναν τέτοιο σύνδεσμο, οι τιμές του αποτελούν μέρος της διεύθυνσης που ζητά ο browser σας και επομένως μπορεί να εμφανίζονται στα τεχνικά δεδομένα αιτημάτων που περιγράφονται παρακάτω. Αν μοιραστείτε έναν σύνδεσμο, όποιος τον λάβει μπορεί να δει αυτές τις τιμές. Μη βάζετε σε έναν σύνδεσμο που μοιράζεστε τίποτα που θεωρείτε εμπιστευτικό.

4. Φιλοξενία και τεχνικά δεδομένα (Cloudflare)

Ο ιστότοπος φιλοξενείται και παρέχεται από την Cloudflare, Inc. (Cloudflare Workers και το δίκτυο διανομής περιεχομένου της). Κάθε φορά που ο browser σας φορτώνει μια σελίδα, η Cloudflare λαμβάνει αναγκαστικά τις συνήθεις τεχνικές πληροφορίες του αιτήματος, οι οποίες μπορεί να περιλαμβάνουν:

  • τη διεύθυνση IP σας και την κατά προσέγγιση τοποθεσία που προκύπτει από αυτήν,
  • τη διεύθυνση που ζητήθηκε, την ημερομηνία και την ώρα,
  • πληροφορίες για τον browser και το λειτουργικό σύστημα (user agent), τη σελίδα παραπομπής και παρόμοιες κεφαλίδες αιτήματος.

Τα δεδομένα αυτά χρησιμοποιούνται μόνο για την παροχή του ιστότοπου, τη διατήρηση της ασφάλειας και της αξιοπιστίας του, την προστασία του από κατάχρηση και επιθέσεις και τη διάγνωση τεχνικών σφαλμάτων. Τα αρχεία καταγραφής αιτημάτων τηρούνται για σύντομο διάστημα, συνήθως μόνο λίγες ημέρες, και δεν χρησιμοποιούνται για τη δημιουργία προφίλ επισκεπτών, δεν συνδυάζονται με άλλα δεδομένα ούτε χρησιμοποιούνται για σκοπούς μάρκετινγκ.

Για την προστασία του ιστότοπου, η Cloudflare μπορεί σε ορισμένες περιπτώσεις να ορίσει ένα απολύτως απαραίτητο cookie ασφαλείας, για παράδειγμα όταν χρειάζεται να ξεχωρίσει τους ανθρώπους από την αυτοματοποιημένη κίνηση. Ο ίδιος ο ιστότοπος δεν ορίζει κανένα cookie.

Η Cloudflare ενεργεί ως εκτελούσα την επεξεργασία για λογαριασμό του ιστότοπου. Περισσότερες πληροφορίες θα βρείτε στην πολιτική απορρήτου της Cloudflare.

5. Αν επικοινωνήσετε μαζί μου

Αν μου στείλετε email, θα χρησιμοποιήσω τη διεύθυνση email σας και το περιεχόμενο του μηνύματός σας μόνο για να σας απαντήσω και να διεκπεραιώσω το αίτημά σας. Τα μηνύματα τηρούνται μόνο για όσο χρειάζεται για τον σκοπό αυτό και στη συνέχεια διαγράφονται.

Ο ιστότοπος παραπέμπει στο GitHub για τον πηγαίο κώδικα και τις προτάσεις νέων εργαλείων. Το GitHub είναι ξεχωριστή υπηρεσία με τη δική του δήλωση απορρήτου, η οποία ισχύει μόλις ακολουθήσετε αυτούς τους συνδέσμους.

6. Νομική βάση

Τα τεχνικά δεδομένα αιτημάτων υποβάλλονται σε επεξεργασία με βάση το έννομο συμφέρον (άρθρο 6 παράγραφος 1 στοιχείο στ΄ του Γενικού Κανονισμού για την Προστασία Δεδομένων της ΕΕ, ΓΚΠΔ): η παροχή ενός λειτουργικού και ασφαλούς ιστότοπου το απαιτεί. Η αλληλογραφία μέσω email υποβάλλεται σε επεξεργασία με την ίδια βάση, ώστε να μπορώ να σας απαντήσω. Η αποθήκευση των επιλογών θέματος και γλώσσας στον browser σας είναι απολύτως απαραίτητη για να παρέχεται μια λειτουργία που ζητήσατε.

7. Διαβιβάσεις εκτός ΕΕ

Η Cloudflare διαθέτει παγκόσμιο δίκτυο και έχει έδρα στις Ηνωμένες Πολιτείες, επομένως τα τεχνικά δεδομένα αιτημάτων μπορεί να υποβάλλονται σε επεξεργασία εκτός του Ευρωπαϊκού Οικονομικού Χώρου. Η Cloudflare συμμετέχει στο Πλαίσιο Προστασίας Δεδομένων ΕΕ–ΗΠΑ (EU–U.S. Data Privacy Framework) και βασίζεται επίσης στις τυποποιημένες συμβατικές ρήτρες της Ευρωπαϊκής Επιτροπής για τη διασφάλιση τέτοιων διαβιβάσεων.

8. Τα δικαιώματά σας

Σύμφωνα με τον ΓΚΠΔ, έχετε δικαίωμα να ζητήσετε πρόσβαση στα προσωπικά σας δεδομένα, διόρθωση και διαγραφή τους, να ζητήσετε περιορισμό της επεξεργασίας τους ή να αντιταχθείτε σε αυτήν, καθώς και δικαίωμα στη φορητότητα των δεδομένων, όπου εφαρμόζεται. Επειδή ο ιστότοπος δεν ταυτοποιεί τους επισκέπτες, συνήθως δεν υπάρχουν δεδομένα που να μπορούν να συνδεθούν με εσάς, αλλά μπορείτε πάντα να ρωτήσετε γράφοντας στο timo.heimonen@proton.me.

Έχετε επίσης δικαίωμα να υποβάλετε καταγγελία σε εποπτική αρχή προστασίας δεδομένων. Στη Φινλανδία αρμόδιος είναι ο Επίτροπος Προστασίας Δεδομένων (Tietosuojavaltuutettu). Μπορείτε επίσης να απευθυνθείτε στην αρμόδια αρχή της χώρας σας (στην Ελλάδα, στην Αρχή Προστασίας Δεδομένων Προσωπικού Χαρακτήρα).
