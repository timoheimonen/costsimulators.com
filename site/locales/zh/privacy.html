隐私政策

costsimulators.com 的设计目标是不收集任何关于你的信息。本页说明在提供网站服务的过程中涉及的少量数据，以及由谁来处理这些数据。

最后更新：2026年9月28日

本页为译文。如与英文版本存在差异，以英文版本为准。

要点

  • 所有计算都在你的浏览器本地运行。工具绝不会把你输入的数字发送到服务器。
  • 没有账户、没有统计分析、没有广告、没有跟踪像素，也没有第三方脚本。
  • 本站不设置 Cookie。唯一保存在你设备上的，是你选择的主题和语言。
  • 本站托管在 Cloudflare 上，Cloudflare 会处理基本的技术请求数据，以便提供和保护网站。

2. 哪些数据留在你的设备上

本站的每个计算器都完全在你的浏览器中通过 JavaScript 运行。你输入的数值，例如时薪、参会人数、价格或数量，只在你的设备上处理，不会传输到、存储在或记录在为本站运行的任何服务器上。

为了记住你偏好浅色还是深色主题，本站会在浏览器的本地存储（local storage）中保存一个值（costsimulators-theme），其中只包含 light 或 dark 这一个词。如果你在语言菜单中选择了语言，本站也会保存这一选择（costsimulators-lang，例如 zh），以便下次用你选择的语言打开网站。这些值绝不会发送到任何地方，你可以随时清除浏览器的网站数据来删除它们。

部分功能会用到浏览器的内置能力：把链接复制到剪贴板、打开设备的分享菜单，以及在会议计时器运行时保持屏幕常亮。这些操作都在本地进行，并且只在你使用时才会发生。

3. 可分享的链接

工具的设置保存在网页地址中，方便你收藏或分享计算结果。当你打开这样的链接时，其中的数值是浏览器所请求网址的一部分，因此可能出现在下文所述的技术请求数据中。如果你分享了链接，收到链接的每个人都能看到这些数值。请不要把你认为需要保密的内容放进分享的链接中。

4. 托管与技术数据（Cloudflare）

本站由 Cloudflare, Inc. 托管和分发（Cloudflare Workers 及其内容分发网络）。每当你的浏览器加载页面时，Cloudflare 必然会收到有关该请求的标准技术信息，其中可能包括：

  • 你的 IP 地址以及据此推断的大致位置；
  • 所请求的网址、日期和时间；
  • 浏览器和操作系统信息（用户代理）、来源页面以及类似的请求头。

这些数据仅用于提供网站、保障网站的安全与稳定、防范滥用和攻击，以及排查技术故障。请求日志只保存很短的时间，通常仅几天，不会用于建立访客画像，不会与其他数据合并，也不会用于营销。

为保护网站，Cloudflare 在某些情况下可能会设置一个严格必要的安全 Cookie，例如需要区分真人访问和自动化流量的时候。本站自身不设置任何 Cookie。

Cloudflare 作为数据处理者，代表本站处理这些数据。更多信息请参阅 Cloudflare 隐私政策。

6. 法律依据

技术请求数据的处理依据是欧盟《通用数据保护条例》（GDPR）第 6 条第 1 款第 (f) 项规定的正当利益：提供一个正常运行且安全的网站离不开这些数据。电子邮件往来基于同样的依据处理，以便回复你。在浏览器中保存主题和语言选择，是提供你所要求的功能所严格必需的。

7. 向欧盟以外传输数据

Cloudflare 运营着全球网络，总部位于美国，因此技术请求数据可能会在欧洲经济区以外处理。Cloudflare 参与了“欧盟—美国数据隐私框架”（EU–U.S. Data Privacy Framework），同时采用欧盟委员会的标准合同条款来保障此类传输。
